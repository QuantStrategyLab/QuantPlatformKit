# QSL 统一量化指标：口径、能力与缺口

适用于既有[回测标准](backtest-standard-v1.zh-CN.md)、[窗口指标](window-metrics-semantics.zh-CN.md)和研究侧 B3 `build_unified_net_report`。这是指标解释与能力目录，不新增策略晋级阈值、候选、交易权限或风险预算。英文版见 [Unified metric catalog](unified-metric-catalog.md)。

## 1. 胜率、盈亏比与 Profit Factor 分开报告

|指标|定义|现有能力与边界|
|---|---|---|
|正收益日比例 `win_rate`|正收益日数 / 全部有效日数，零收益日计入分母|旧窗口指标已实现；不是逐笔交易胜率|
|剔零胜率|正收益观察数 /（正 + 负收益观察数）|窗口 `daily_win_rate_ex_zero` 已实现；B3 可选 `net_win_rate_ex_zero_per_period`，全零样本不可计算|
|平均盈亏比 Payoff ratio|平均盈利幅度 / 平均亏损幅度绝对值|Kelly 有均值输入；B3 可选 `net_payoff_ratio_per_period`。缺正或负任一侧不能假造均值|
|盈利因子 Profit Factor|盈利总和 / 亏损总和绝对值|旧窗口 `profit_factor` 基于日收益；B3 可选 `net_profit_factor_per_period`。无亏损观察不可计算，只有亏损时真实值为 0|
|样本平均净收益|同频净收益率算术均值，包含零收益观察|B3 可选 `mean_net_return_per_period`，不是未来利润预测，也不是复利增长|
|逐笔胜率、盈亏比、盈利因子与 expectancy|以已闭合交易的净 P&L 为观察单位|回测标准已要求逐笔胜率/expectancy，但上述日收益/单期输入不提供逐笔实现；仍需真实配对成交和记账合同|

单期新诊断通过 `include_outcome_diagnostics=True` 加入 B3，默认保留原八项输出。所有新结果带正/负/零观察数、`aggregation_level=return_observations_not_trades`、`input_basis=same_period_net_returns`、`descriptive_only=true`。未知/无定义或数值溢出/非零下溢时 `UNCOMPUTABLE`、`value=null`、明确原因；不写无穷大或假 0。完整样本的精确净和为 0 时，平均收益的 0 是已知值；全零和正负收益精确相消均属于这种情况。

同一口径下，`Profit Factor = 平均盈亏比 × 盈利观察数 / 亏损观察数`；它不是平均盈亏比本身。包含零观察的平均收益为 `p正 × 平均正收益 − p负 × 平均亏损幅度`，这里两个概率均以全部观察为分母。剔零胜率不能直接代入这个含零均值公式。

高胜率仍可能负期望；低胜率也可能由较高盈亏比获得正期望。胜率和盈亏比要一起看净收益、样本量、持有周期与尾部损失，不能单独设全系统及格线。算术均值与净对数增长也不同，均值为正不保证复利增长为正。

## 2. 成熟系统的核心指标分组

|维度|重要指标|当前统一能力|
|---|---|---|
|收益与基准|净对数增长、累计收益、CAGR、同窗超额收益、Alpha/Beta及跟踪误差|B3 提供净单期对数增长；窗口提供累计收益/CAGR/基准对比、Alpha/IR和对齐计数；其他基准归因/跟踪误差需明确投影与口径|
|风险调整收益|Sharpe、Sortino、Calmar、Information Ratio|窗口已实现；B3 提供单期 ddof=1 Sharpe。频率、无风险基准和年化口径必须对齐|
|亏损与尾部|最大回撤、回撤金额/持续与恢复期、CVaR/ES、VaR、极端情景损失|B3 含初始 NAV 的回撤和精确最差5%质量 CVaR95；回撤金额/恢复期、VaR及压力情景仍需单列输入/统一投影|
|收益分布|胜率、盈亏比、Profit Factor、平均净收益、连续亏损、样本量与置信区间|前四项研究诊断已提供；逐笔/连亏依赖记账与观察单位；bootstrap 能力已有，不自动给新诊断附置信区间|
|统计可靠性|PSR、DSR、MinTRL、PBO、walk-forward/OOS、参数稳定性|统计原语与 B3 已有；PBO/bootstrap是独立函数，真实累计试验账本和冻结假设仍须核验|
|执行与成本|换手、佣金/价差/冲击/融资成本、成本拖累、滑点/成交率/拒单率/执行延迟|A2 成交成本模型和 B3 成本拖累已有；真实执行质量及统一分母需订单/报价/成交时间证据|
|组合与容量|相关性、集中度、风险贡献、现金与敞口、流动性、可承载资金规模|现有风险/组合模块与报告分工；不是 B3 已完成的统一容量或实时组合投影|
|运行与数据|来源/PIT、新鲜度、持仓资金对账、重复/未知订单、报告送达与恢复|依赖实际 runtime/来源/回执；源码 CI 成功不能替代这些运营证据|

这些是按研究/交易/组合/运营目的选择的目录，不要求每种策略机械使用全部指标。被候选预注册要求的项缺失时必须披露；报告、排序和否决角色及阈值仍由既有冻结合同决定。

## 3. 必须绑定的统一口径

1. 标明观察单位：交易、交易日、自然日或小时；写清正负/零的分母、交易数和持仓覆盖范围。B3 `per_period` 不自动宣称日频或年化。
2. 先对齐成本、资金流、价格复权、币种、现金/融资腿及信号/成交时点，再比较收益。`net_returns` 的命名不核验实际成本是否正确入账；需绑定 A2 对账与来源证据。
3. 股市交易日与24×7加密使用明确日历/年化基数。生命周期 Sharpe 默认 ddof=0，研究推断 ddof=1，不能不说明就比较。
4. 逐笔统计先冻结 FIFO/其他配对方式、分批成交/部分平仓、多腿组合、切换归属、费用与 FX 分配、持有期及未平仓处理；不能把一张订单、一笔 fill 或一个正收益日直接当一次获利交易。
5. 单列样本量、窗口、数据身份与可计算状态。没有亏损样本不等于没有亏损风险；缺交易记录、缺价格或缺净值不能补 0。
   旧窗口某些无定义比率为兼容仍保留 NaN，消费者必须显式处理，不能转为已知 0。
6. DSR 绑定真实全累计试验（含失败/拒绝/中断等冻结口径），PBO/WFA/OOS保持时点和隔离。声明账本数、指标实现或合成回归通过均不证明统计优势或实盘采用。

## 4. 本批与后续

- 本批只补 B3 可选单期研究诊断和目录；既有窗口字段、原八项结果、晋级/风险/仓位和生产 pin不变。
- 逐笔统计继续作为缺口：先取得/冻结完整成交记账合同，随后单独实现和验证；不读取真实账户或生成真实交易成绩。
- 回撤恢复/容量/实际执行质量的标准化按各自证据推进，不用自选阈值替代 B1/B2/B4 冻结。B4 后验更新与 E1 仍是独立阶段。
